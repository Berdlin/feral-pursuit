MISSION BRIEFING

PHASE 1: SCAVENGING

You have 25 Seconds before the sun sets. Search the map for 📦 Chests. They contain weapons, armor, or healing items. Be careful: some chests are trapped.

PHASE 2: THE HUNT

When the timer hits zero, the Blood Moon rises. Wolves will spawn and hunt you. You must kill them to survive until the next day.

OPERATOR CONTROLS

🖥️ DESKTOP

  • WASD : Move Operator
  • SPACE : Attack (Sword)
  • Shift + A : Local Admin (Beka_ei)
  • Shift + G : Global Admin (Beka_ei)
  • E : Open Chest / Interact
  • Q : Open Inventory
  • M : Toggle Minimap
  • O : Dog Stats
  • 1-9 : Use Item

📱 MOBILE

  • Joystick (Left) : Move
  • ⚔️ Button : Attack
  • 👋 Button : Loot Chest
  • INV Button : Inventory
  • Eye Icon : Toggle Minimap
